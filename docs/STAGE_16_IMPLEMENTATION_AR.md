# Stage 16 — Eino Backend

تم نقل Eino إلى بوابة Association API بشكل كامل:

- Flutter يرسل إلى `/api/v1/eino/chat` فقط.
- Worker هو الوسيط الوحيد بين التطبيق وLeo-OmniRoute.
- مفتاح OmniRoute لا يظهر في Flutter أو Dashboard.
- Eino يدعم الزائر بسياق عام، والطالب المسجل يحصل على سياق أكاديمي محدود من D1 (القسم والفصل فقط).
- سياق المحادثة اختياري ومحدود الحجم.
- لا يتم حفظ نص المحادثات أو الرسائل في D1؛ يتم حفظ عدادات الاستخدام فقط.
- حد Eino: 20 طلبًا لكل نافذة 10 دقائق لكل طالب، أو لكل IP مجزأ للزائر.
- نموذج OmniRoute يجب أن يكون بصيغة `provider/model`؛ القيمة `auto` مرفوضة صراحة.
- مهلة الاتصال بالـgateway: 20 ثانية.
- إجابة فارغة أو فشل المزود يعاد برسالة خطأ موحدة.
- رسائل السياق تعامل كبيانات غير موثوقة ولا تستطيع تغيير قواعد Eino الأساسية.
