# المرحلة 10 — الإعلانات الرسمية والإشعارات

تم توحيد الإشعارات حول Association API + D1.

## المنجز
- الإعلانات الرسمية مصدرها D1 فقط.
- Dashboard يستطيع نشر الإعلان ثم طلب إرساله إلى الطلاب المستهدفين.
- الاستهداف اختياري بالقسم والفصل الدراسي.
- إنشاء notification_targets يمنع التكرار.
- عداد غير المقروء ضمن استجابة الطالب.
- تعليم إشعار واحد أو مجموعة كمقروء.
- تسجيل أجهزة الطالب وقنواتها في D1 بدون وضع أسرار مزود Push داخل التطبيق.
- إنشاء Queue داخل D1 لقنوات `in_app` و`push`.
- Audit Log لعملية الإرسال.

## Push الحقيقي
هذه المرحلة تجعل النظام Push-ready ولا تربطه بمزود خارجي دون مفاتيحه الرسمية. الصفوف ذات قناة `push` تنتظر عامل الإرسال/المزود الذي سيضاف لاحقًا. الإشعارات داخل التطبيق تعمل عبر D1 مباشرة.

## مبدأ الأمان
Flutter لا يعرف أسرار Google أو OmniRoute أو أي مفتاح إرسال. التسجيل يحفظ رمز الجهاز فقط بعد مصادقة الطالب.
