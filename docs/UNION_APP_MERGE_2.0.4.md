## نطاق النقل

نُقلت ملفات تطبيق Union-App إلى موضع تطبيق الطلاب داخل Monorepo، وليس إلى جذر المستودع. تمت مزامنة ملفات:

- `flutter/lib` إلى `apps/student/lib`
- `flutter/test` إلى `apps/student/test`
- `flutter/assets` إلى `apps/student/assets`
- `flutter/android` إلى `apps/student/android` مع الحفاظ على إعدادات بناء وتوقيع Monorepo عند نقاط التعارض.
- `pubspec.yaml` و`pubspec.lock` وملفات إعداد Flutter إلى `apps/student/`.

تم التحقق آلياً من وجود كل ملفات المصدر في المسارات الأربعة المنقولة: 101 ملف Dart/مورد في `lib`، و14 ملف اختبار، و4 ملفات أصول، و23 ملف Android. لم تُسجل ملفات مفقودة من هذه المجموعات.

## توافق Monorepo

- بقي تطبيق الطلاب داخل `apps/student/` وبقي تطبيق الإدارة في مساره المستقل.
- بقيت ملفات Worker ضمن `services/api/` ومخطط D1 ضمن migrations الخاصة به.
- لم يتم نسخ Backend Union-App فوق Backend Monorepo؛ أضيفت مسارات توافقية إلى Worker الحالي.
- أضيفت migrations جديدة `0037` إلى `0039`، دون تعديل أو إعادة ترقيم migrations السابقة.
- بقي `applicationId` هو `com.leoassociation.app`.
- حُفظت حواجز التوقيع والبناء وإعدادات Gradle الخاصة بـMonorepo.
- أزيل اعتماد Llama المحلي وقيد `minSdk` الذي كان مرتبطاً به.
- أضيفت/وُحدت تبعيات Firebase Messaging والإشعارات المحلية، وتم تمرير جسم طلب DELETE في طبقة النقل حتى يصل طلب إلغاء تسجيل جهاز الإشعارات إلى API.
- حُفظت تحسينات Monorepo غير المتعارضة، ومنها دليل التسجيل الموجّه، مؤشر انقطاع الاتصال، واجهة السوق الحية، وحركة وجه Eino.
- عُدلت تجربة تنزيل ملفات الدراسة لتحتفظ بالنسخة الداخلية غير المتصلة وتصدر نسخة إلى مجلد Android Downloads عند توفر قناة Android الأصلية.

## توافق API وD1

أضيفت مسارات متوافقة لميزات الطالب التي تعتمد عليها واجهات Union-App، تشمل الملف الشخصي العام، المحادثة العامة والردود والإبلاغ والحذف، حذف إشعار الطالب، المواد الامتحانية، الملاحظات/التغذية الراجعة، التحليلات المجهولة، ومحادثات Eino المحفوظة وبعض عمليات الملفات.

أضيفت جداول/حقول وفهارس عبر migrations تكميلية. لم يُستبدل مخطط Monorepo بمخطط Union-App. مسارات التحليلات المضافة مصممة لتجنب تخزين معرف الطالب أو عنوان IP أو وكيل المستخدم أو محتوى الرسائل ضمن سجلات التحليلات.
