# المرحلة 8 — لوحة مراقبة إينو

تم دمج مراقبة Eino داخل الصفحة الرئيسية للوحة تحكم TRINEX بدلاً من تركها كنقطة API منفصلة.

## ما يظهر في اللوحة
- عدد الطلبات الناجحة خلال آخر 24 ساعة.
- عدد رفض الحصص اليومية/العامة أو حد النافذة.
- أخطاء OmniRoute/المزود.
- متوسط زمن الاستجابة للطلبات التي تقيس زمن المزود.
- حدود الطالب والزائر والحد العام اليومية الحالية.
- شارة حالة مختصرة: مستقر / تنبيه / يحتاج مراجعة.

## المصدر
تستخدم اللوحة `GET /api/v1/admin/security/eino-usage?hours=24` عبر Association API، مع صلاحية `dashboard.read`.

## الخصوصية
تبقى بيانات المراقبة مجمعة فقط. لا تعرض اللوحة نصوص المحادثات أو الـ prompts أو response أو IP أو student_id أو مفاتيح المزود.

## المسؤوليات
- TRINEX: التحكم في الوصول، الحصص، burst rate limit، وسجل الاستخدام المجمع.
- OmniRoute: اختيار المزود، fallback، circuit breaker، provider quota/cost/health.
