# المرحلة 18 — نظام التصميم الموحد

تم توحيد اللغة البصرية للتطبيق في طبقة مركزية بدل توزيع الألوان والمسافات والزوايا داخل الشاشات.

## ما تم
- هوية برتقالية موحدة للرابطة.
- Design Tokens مركزية للمسافات والزوايا وأحجام عناصر التحكم والحركات.
- Color system دلالي: نجاح، تحذير، خطأ، معلومات.
- توحيد Typography وأوزان العناوين والنصوص.
- توحيد AppBar وNavigationBar والأزرار وحقول الإدخال والبطاقات والـ Chips.
- إضافة `AppCard` و`AppButton` و`AppSection` كلبنات مشتركة للمراحل التالية.
- تحديث `FeatureCard` و`SectionTitle` لاستخدام الـ tokens.
- الإبقاء على انتقالات الصفحات الهادئة والخفيفة.
- لا توجد أي إضافة للإعلانات التجارية.

## فلسفة الاستخدام
الشاشات القادمة يجب أن تستخدم `DesignTokens` ومكونات `shared/widgets` بدل أرقام وألوان جديدة محلية كلما أمكن.

## الإصدار
`2.1.0+12`

## التحقق
تم فحص ملفات Dart وتحديثات الاستيراد آليًا. بيئة التنفيذ الحالية لا تحتوي Flutter/Dart CLI، لذلك لا يتم الادعاء بتشغيل `flutter analyze` أو `flutter test` محليًا.
