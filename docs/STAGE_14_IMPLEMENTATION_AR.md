# Stage 14 — الشارات والإنجازات

- إضافة كتالوج شارات قابل للإدارة من Dashboard.
- قواعد مدعومة: `xp_total`, `level`, `completed_materials`, `progress_events`.
- منح تلقائي من Worker مع `UNIQUE(student_id,badge_id)` لمنع التكرار.
- `/api/v1/badges` يعيد المكتسب والمقفل والعدادات.
- فحص الشارات بعد أحداث التقدم وبعد جلب صفحة الشارات، لذلك يمكن احتساب الشارات المستحقة للحسابات السابقة.
- Flutter: شاشة الشارات وحالتا المكتسبة/المقفلة وربطها بملف الطالب.
- الشارات المرجعية قابلة للتعديل من Dashboard ولا توجد مكافآت تجارية أو إعلانات.
