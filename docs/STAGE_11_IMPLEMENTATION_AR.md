# المرحلة 11 — ملف الطالب والمصادقة داخل Flutter

## المنجز
- ربط Flutter فعليًا بـ Student Auth في Association API.
- حفظ Access/Refresh Token محليًا عبر SharedPreferences.
- إرسال Bearer Token تلقائيًا مع الطلبات.
- تدوير جلسة الوصول تلقائيًا عند 401 باستخدام Refresh Token.
- مسح الجلسة عند فشل refresh.
- تسجيل دخول الطالب بالرقم الجامعي وكلمة المرور/رمز التحقق.
- شاشة ملف الطالب الفعلي من D1.
- عرض القسم والفصل والمستوى وXP.
- تسجيل الخروج الحقيقي.
- تحديث `student/me` ليعيد القسم والفصل.

## الأمان
- لا يتم تخزين كلمة المرور.
- لا توجد أسرار API داخل Flutter.
- Access/Refresh tokens فقط في التخزين المحلي.
- القسم الدراسي لا يحدده العميل؛ API يأخذه من حساب الطالب.

## ملاحظة
التطبيق ما زال يسمح بالوصول العام كزائر. المواد والجدول يتطلبان جلسة طالب كما يفرضها Worker.
