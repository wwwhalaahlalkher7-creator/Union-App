# Stage 12 — تتبع التقدم الدراسي

## ما تم تنفيذه
- تتبع فتح الملف والتقدم والإكمال عبر API محمي بجلسة الطالب.
- الخادم هو مصدر الحقيقة للتقدم؛ لا يقبل XP من العميل.
- التقدم لا ينخفض.
- يمنع القفزات الكبيرة في التقدم ويضع حدًا زمنيًا للتحديثات.
- الإكمال المبكر جدًا مرفوض قبل وجود وقت دراسة كافٍ.
- تسجيل وقت نشاط محدود لمنع تضخيم الوقت.
- سجل أحداث مستقل `material_progress_events` للتدقيق والتحليل لاحقًا.
- صفحة `تقدمي الدراسي` تعرض الملفات التي بدأ بها الطالب، نسبة التقدم، الإكمال ووقت الدراسة.
- ربط المواد والجدول والإشعارات بعميل API يحمل جلسة الطالب.

## XP
لا يتم منح XP في هذه المرحلة. Stage 13 سيستخدم أحداث التقدم المقبولة فقط، مع قواعد وحدود server-side.

## الترقية
تم رفع إصدار Flutter إلى `1.5.0+6`.
