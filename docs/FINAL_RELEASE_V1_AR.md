# الإصدار النهائي V1 — رابطة كلية الهندسة والعمارة

## حالة الإصدار

- إصدار التطبيق: **2.6.0+17**
- الحالة البرمجية: **Final Release Candidate / Feature Freeze مكتمل**
- Android Application ID: `com.leoassociation.app`
- المصدر المركزي للنسخة: `flutter/VERSION`

## ما تم إغلاقه

- تجميد الميزات الجديدة.
- تثبيت هوية Android وعدم تغيير `applicationId`.
- ربط `versionCode` و`versionName` بمصدر النسخة المركزي.
- فحص migrations من `0001` إلى `0013` بالتسلسل.
- فحص Backend وDashboard JavaScript.
- فحص سياسة Source of Truth.
- منع عودة Apps Script/Airtable كطبقة تشغيلية.
- منع إعادة نظام الإعلانات التجاري.
- إبقاء Dashboard/API مصدر التشغيل للمحتوى والبيانات الإدارية.
- إضافة بوابة فحص نهائية قابلة للتنفيذ في CI.

## فحوص البيئة الحالية

تم اجتياز الفحوص الثابتة ومحاكاة migrations محليًا.

**لم يتم تنفيذ Flutter analyze/test/build في بيئة العمل الحالية لأن Flutter SDK غير مثبت فيها.** لذلك لا ندّعي نجاح هذه الخطوات قبل تشغيلها في CI أو بيئة Flutter فعلية.

## توقيع Android

الإصدار الحالي قابل للاختبار باستخدام debug signing، لكنه **ليس توقيع إنتاج**.

قبل النشر العام يجب استخدام keystore الإنتاج الحقيقي، ويجب أن يكون نفس مفتاح الإصدار السابق إذا كان المطلوب تحديث التطبيق فوق النسخة المثبتة.

لا يوجد أي مفتاح توقيع حقيقي داخل المستودع أو داخل الحزمة.

## النشر

لا يتم تنفيذ نشر Cloudflare/D1 تلقائيًا من هذه الحزمة، لأن بيانات الإنتاج والـ credentials الفعلية ليست جزءًا من المشروع.

المسار الإنتاجي المعتمد:

`Flutter / Dashboard → Association API → D1 / Drive / Notifications / Eino → Leo-OmniRoute`

## قاعدة ما بعد الإصدار

بعد اعتماد 2.6.0+17، أي تعديل لاحق يجب أن يكون لإصلاح خلل أو تحسين أمان/أداء/بنية أو إضافة ميزة مع إصدار جديد؛ لا يتم تعديل البيانات التشغيلية يدويًا في الكود أو D1.
