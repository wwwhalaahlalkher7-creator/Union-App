# تدقيق عقد Backend لتطبيق الإدارة

هذه مراجعة ساكنة لمصدر الخادم المرفق في `services/api`. لم تُنفّذ طلبات مباشرة على بيئة الإنتاج في هذه الجولة.

## الوحدات التي تستخدم مسارات موجودة

| الوحدة | مسارات Backend | العمليات التي تستخدمها الواجهة |
|---|---|---|
| لوحة المعلومات وإحصاءات النظام | `GET /admin/dashboard/overview` | قراءة الأعداد التي يعيدها الخادم فقط؛ لا يُستدعى مسار تحليلات غير موجود |
| الأخبار | `/admin/news` | `GET`, `POST`, `PATCH`, `DELETE` |
| الفعاليات | `/admin/events` | `GET`, `POST`, `PATCH`, `DELETE`؛ لا تستخدم `/admin/activities` |
| الإنجازات | `/admin/achievements` | `GET`, `POST`, `PATCH`, `DELETE` ورفع الصور عبر `/admin/media` |
| الإعلانات والإشعارات | `/admin/announcements`, `/admin/notifications`, `/admin/notifications/send` | إدارة سجل الإعلان وموعده وجمهوره وتجهيز قائمة المستهدفين للإرسال |
| الطلاب | `/admin/students`, `/departments`, `/semesters` | قراءة وإنشاء وتعديل وتعطيل وحذف الطالب وفق صلاحيات الخادم |
| الموظفون | `/admin/staff` | قراءة وإنشاء وتعديل الدور والحالة وكلمة مرور موظف آخر وحذف الحساب |
| المواد الدراسية | `/admin/subjects`, `/admin/materials` | CRUD للمواد والملفات المسجلة |
| الجداول | `/admin/schedule` | CRUD للجداول؛ يتحقق الخادم من المادة والقسم والفصل وصحة الوقت |
| Drive وملفات PDF | `/admin/drive/sync`, `/admin/drive/sync-status`, `/admin/drive/folders`, `/admin/drive/items/:id`, `/admin/drive/files` | مزامنة، عرض حالة المزامنة، إنشاء مجلد، إعادة تسمية مجلد/ملف ورفع PDF بحجم يصل إلى 20MB |
| فهرسة Eino | `/admin/eino/materials/:id/index`, `/admin/security/eino-usage` | إعادة الفهرسة وقراءة بيانات الاستخدام المجمعة |
| الامتحانات | `/admin/exams` | إنشاء مجلد الامتحانات، رفع PDF، إعادة تسمية الملف وحذفه |
| السوق | `/admin/market-items` | CRUD كامل لعناصر السوق مع بيانات العربية والإنجليزية والقسم والحالة وروابط HTTPS |
| الشارات | `/admin/badges` | إنشاء وتعديل وتفعيل وتعطيل؛ الحذف النهائي مرفوض من الخادم |
| التعليقات | `/admin/moderation/comments`, `/admin/moderation/comments/:id` | عرض حسب الحالة وتغيير الحالة إلى `visible` أو `hidden` أو `deleted` |
| الأمان | `/admin/audit-logs`, `/admin/security/auth-events` | قراءة سجلات التدقيق ومحاولات المصادقة الفاشلة/المقفلة؛ لا توجد عمليات تعديل من الواجهة |
| إعدادات الموقع | `/admin/settings`, `/admin/settings/:key` | قراءة الإعدادات وحفظ قيمة JSON بمفتاح لا يتجاوز 128 حرفًا |
| حساب الموظف | `/auth/staff/me`, `/auth/staff/change-password`, `/auth/logout` | قراءة الهوية وتغيير كلمة المرور والخروج |

## حدود يجب عدم إخفائها

- **استيراد الماسح الضوئي:** لا توجد routes أو مخطط قاعدة بيانات أو handlers لـ`/admin/imports*` في Backend المرفق. أزيلت شاشة الاستيراد والأزرار التي كانت تعتمد عليها حتى لا يبقى تدفق يبدو قابلًا للاستخدام لكنه يفشل عند أول طلب. إعادة بناء الاستيراد تتطلب إضافة العقد إلى Backend أولًا ثم إضافة اختبارات تكامل ومراجعة واعتماد مناسبة.
- **تعديل ملف تعريف موظف الإدارة:** توجد `GET /auth/staff/me` ولا يوجد `PATCH /auth/staff/profile` أو مسار مكافئ؛ تعرض الصفحة الملف الشخصي للقراءة وتوفر تغيير كلمة المرور المدعوم فقط.
- **تعيين طالب مشرفًا:** لا يوجد `PATCH /admin/students/:id/moderator` ولا حقل `is_moderator` في عقد CRUD الحالي؛ أزيل خيار تعيين المشرف غير المدعوم.
- **التحليلات:** لا يوجد `/admin/analytics/overview`؛ تستخدم الواجهة `/admin/dashboard/overview` ولا تدّعي إحصاءات أكثر مما يعيده Backend.
- **مراقبة Eino:** المسار المعتمد هو `/admin/security/eino-usage`، وهو يقدّم ملخصات ومجموعات زمنية مجمعة فقط، وليس قائمة محادثات أو سجلًا لكل مطالبة.
- **الإشراف:** يدعم الخادم التعليقات فقط في وحدة الإشراف الحالية؛ لم تُبقَ روابط وهمية إلى صناديق تقارير أو بلاغات محادثة غير موجودة.
- **إعدادات الحساب:** لا يتوفر تعديل الاسم أو البريد للموظف عبر API الحالي.

## الصلاحيات

الأدوار التي تستخدمها الواجهة هي `super_admin`, `content_manager`, `academic_manager`. تقليل عناصر التنقل ليس بديلًا عن فحوصات الخادم؛ يجب أن تظل الطلبات محمية بـpermissions في Backend. إدارة الموظفين والإعدادات وسجلات التدقيق تتطلب صلاحيات مدير النظام، بينما إدارة المحتوى والشؤون الأكاديمية مرتبطة بصلاحيات كل وحدة.

## التحقق

تغطي الفحوصات `ci/admin_app_contract_check.py`, `ci/admin_crud_check.py`, `ci/backend_api_contract_check.py`, `ci/backend_schema_check.py` و`ci/eino_monitor_check.py` مطابقة العقود الأساسية. يجب أن تنجح كذلك `flutter analyze` والاختبارات والبناء في CI؛ لم يكن Flutter/Dart مثبتًا في بيئة التحرير المحلية، ولم تُجرَ اختبارات حية ضد الإنتاج.
