# TRINEX Admin

تطبيق الإدارة الرسمي لمنصة TRINEX، مبني بـ Flutter ويستهدف Android وWindows. هذا التطبيق جزء من المستودع الموحد، ويتصل بالخدمات الموجودة في `services/api`.

**الإصدار الحالي:** `1.1.0+1` (`v1.1.0`).

## التشغيل

```bash
cd apps/admin
flutter pub get
flutter analyze --no-fatal-infos
flutter test
flutter build apk --release
flutter build windows --release # يتطلب Windows
```

## عنوان API

العنوان الافتراضي مضبوط في `lib/src/api_service.dart`. يمكن تغييره عند البناء عبر:

```bash
flutter run --dart-define=TRINEX_API_BASE_URL=https://your-api.example/api/v1
```

## الوحدات المتصلة بعقد الخادم

يشمل التطبيق لوحة المعلومات، إحصاءات النظام المتاحة، الطلاب، حسابات الموظفين والأدوار، الأخبار والفعاليات والإنجازات، الإشعارات المجدولة، المواد والجداول الأكاديمية، مزامنة Drive ورفع ملفات PDF، إدارة عناصر السوق والشارات والامتحانات، إشراف التعليقات، إعدادات الموقع، سجل التدقيق ومراقبة Eino.

## حدود العقد الحالي

- لا يوفّر الـBackend الموجود في المستودع مسارات `/admin/imports*` الخاصة باستيراد الطلاب والجداول بالماسح؛ لذلك أزيلت أزرار الاستيراد التي كانت تستدعي مسارات غير موجودة بدل عرض وظيفة مكسورة. لا تعود هذه الوظيفة متاحة حتى تُضاف مساراتها ومخطط البيانات واختبارات العقد إلى الخادم.
- لا توجد واجهة API لتعديل ملف تعريف موظف الإدارة أو لتعيين طالب مشرفًا؛ لا تعرض الواجهة عناصر تحاول تنفيذ هذه العمليات غير المدعومة.
- مراقبة Eino تعتمد على بيانات مجمعة من `/admin/security/eino-usage`، ومراجعة الإشراف مقتصرة على تعليقات الطلاب التي يدعمها الخادم.
- إخفاء الأقسام في واجهة Flutter لسهولة الاستخدام لا يحل محل تفويض الصلاحيات في الخادم.
